# LRD-01A evidence

This directory contains measurement evidence for LRD-01A only.

`replay_closure_coverage_v1.json` is a strict, machine-readable Phase-0 coverage matrix bound
to the measured baseline `main @ a884073591295af106baf1d6d87cf178830db315`.

The matrix is measurement evidence, not Product state, CCL history, Gold, authorization,
release authority or independent certification. Its design gate means all fixed
trust-critical dependencies are explicitly classified; it does not mean every dependency is
already preserved or replayable.
